Topology:

- James R. Munkres, *Topology*, 2nd edition, Part II.

Algebra supplements:

- John B. Fraleigh and Neal Brand, *A First Course in Abstract
  Algebra*, 8th edition.
- David S. Dummit and Richard M. Foote, *Abstract Algebra*,
  3rd edition.
